## 运动与颜色

- 未滑出的文字沿原路径向出口移动，保持花或叶的颜色，不受重力影响。
- 文字中心越过路径出口时，立即使用段落颜色；此时仍是文字绳，不改变字号、不进入段落排版。
- 已滑出的字素各自作为物理节点，使用固定 120 Hz Verlet、重力、阻尼、相邻距离约束和按字宽设置的碰撞半径；两条绳的自由字素之间也参与碰撞。下落文字保持正向，底部形成有厚度的自然堆叠。
- 下落动力参数对齐 textstring：阻尼 0.97（整理稳定期 0.85）、重力 1400 px/s²（120 Hz 步长下终端落速约 390 px/s）。终端落速必须明显高于 280 px/s 的出绳速度：绳为不可压缩链，一旦下落慢于输送，多余绳长会在半空折成发卡弯，字面呈现为并排的两列。速度上限 1500 px/s 仅作防爆保护。
- 碰撞调度：下落阶段每 3 轮约束做一次碰撞与边界钳制（高速冲击下逐轮碰撞会注入能量、放大约束残差），整堆进入稳定期后改为逐轮碰撞。碰撞单轮修正位移上限 2 px，防止字素互相穿透形成无法解开的交叉。
- 拖拽松手时清空自由字素速度（同 textstring 的解锁处理），避免蓄积的约束速度把绳甩出拉伸尖峰。
- 有效拖拽松手只放开手指约束，并继续沿路径输送剩余文字；不会一次释放全部节点，也没有虚拟手继续牵引。
- 两条绳全部滑出、全部字素通过地面接触、字间接触或相邻绳段获得支撑，且整堆低速稳定 0.35 秒后，整理 1.8 秒，再整体放大 1.6 秒。没有超时强制排版。
- 稳定期沿用与下落相同的阻尼（0.97），让末端字列自然倒塌落地；对连续 0.2 秒低于 0.9 px/frame 的字素额外压制速度以消除堆内蠕动（约 0.1 px/frame，低于 0.35 px/frame 静止门槛）。刚起落的字素约 0.08 秒即离开慢速区，不受影响，因此判定通过的瞬间最后一个字必然已经落地。`supported()` 为 O(n²)，settle 期按 10 步缓存以控制每帧开销。settle 典型用时约 2.4 秒。
- 速度按钮循环切换 1×、1.5×、2×、0.5×，拖拽跟手保持原速。暂停冻结运动，短拖回位，取消恢复拖动前状态。
- 原字素只使用一次，保留最终原文次序和显式换行；不补字、不删字、不淡出。

字号、段落布局、配色及背景上传功能沿用现有设置。范围根据两条路径总长动态计算。设置与上传背景仅保存在当前页面内存。

碰撞与边界处理参考 [pushmatrix/textstring](https://github.com/pushmatrix/textstring/blob/main/index.html) 的字素碰撞思路，独立实现空间网格与支撑网络。未引入其运行时代码。
